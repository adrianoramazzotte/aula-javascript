Ambiente de Trabalho e IA Gratuita

Como montar tudo no VS Code, sem pagar nada e sem cartão de crédito.

Faça isso ANTES da primeira aula prática. A instalação leva de 20 a 30 minutos com internet razoável. Chegar na aula com o ambiente pronto é o que garante que você vai programar em vez de assistir download.

1. O que instalar

  1. Visual Studio Code Baixe em code.visualstudio.com. É o editor onde vamos escrever todo o código da disciplina. Instalação padrão, pode clicar em "Avançar" em tudo.
  2. Node.js (versão LTS) Baixe em nodejs.org e escolha a opção LTS (a versão estável, não a "Current"). É o que permite rodar JavaScript fora do navegador, direto no terminal.
  3. Confirme que deu certo Abra o VS Code, pressione Ctrl+' para abrir o terminal integrado e digite os dois comandos abaixo. Se aparecer um número de versão em cada um, está tudo certo. 
    node --version
npm --version
  4. Extensões do VS Code Abra a aba de extensões (Ctrl+Shift+X) e instale:
    • Live Server — abre sua página HTML no navegador e recarrega sozinho ao salvar.
    • Code Runner — roda um arquivo .js com Ctrl+Alt+N e mostra o resultado dentro do VS Code.
    • Portuguese (Brazil) Language Pack — opcional, deixa a interface em português.

2. Rodando seu código

Na disciplina você vai escrever JavaScript de duas formas diferentes, e cada uma roda de um jeito:

JavaScript puro (lógica, variáveis, laços, funções)

Crie um arquivo exercicio.js e rode com Ctrl+Alt+N (Code Runner), ou pelo terminal:

node exercicio.js

O resultado do console.log() aparece no painel inferior do VS Code.

JavaScript no navegador (HTML, CSS, DOM, eventos)

Crie o index.html, clique com o botão direito e escolha "Open with Live Server" (ou clique em Go Live no canto inferior direito). O navegador abre e atualiza sozinho a cada vez que você salvar.

Aqui o console.log() aparece no DevTools do navegador: tecle F12 e vá na aba Console. É lá que os erros de JavaScript também aparecem — acostume-se a deixar essa aba aberta.

3. IA gratuita dentro do VS Code

Você não precisa de assinatura paga para ter uma IA ajudando. A ordem abaixo é a recomendada — comece pela primeira.

Opção A — GitHub Copilot (plano gratuito)

  1. Crie uma conta no GitHub Em github.com, gratuito. Você vai precisar dela também para entregar os trabalhos.
  2. Ative o Copilot no VS Code Clique no ícone do Copilot na barra superior do VS Code e faça login com a conta do GitHub. O plano gratuito é liberado na hora, sem cartão.
  3. Use no dia a dia
    • Sugestões aparecem em cinza enquanto você digita — Tab aceita.
    • Ctrl+Alt+I abre o chat lateral, que enxerga o arquivo aberto.
    • Selecione um trecho e tecle Ctrl+I para perguntar sobre aquele pedaço específico.

Copilot Pro de graça para estudantes. O GitHub Student Developer Pack (education.github.com/pack) libera o Copilot Pro sem limites enquanto você for estudante. A comprovação pode ser feita com documento de matrícula ou carteirinha — não é obrigatório ter e-mail institucional. Vale gastar 15 minutos nisso: resolve o semestre inteiro.

Opção B — Quando o limite gratuito acabar

Instale a extensão Cline (ou Roo Code) no VS Code e conecte uma chave gratuita do Google AI Studio (aistudio.google.com). A chave é gratuita, não pede cartão e tem um limite diário bem folgado. Você continua com um assistente de IA dentro do editor.

4. Não tenho como instalar nada

Se você usa Chromebook, um computador do trabalho com restrições ou o laboratório da faculdade, use estas alternativas 100% no navegador:

  • StackBlitz (stackblitz.com) — roda projetos JavaScript completos no navegador.
  • CodeSandbox (codesandbox.io) — semelhante, bom para projetos com HTML e CSS.
  • vscode.dev — o próprio VS Code no navegador; edita arquivos, mas não roda Node.

5. Regras de uso da IA na disciplina

A IA é permitida e incentivada — mas do jeito certo. Quem pede o exercício pronto entrega funcionando e chega na prova sem saber escrever um laço. Use a IA como monitor particular, não como máquina de colar resposta.

Não vale

  • Pedir o exercício resolvido e entregar sem entender.
  • Colar o enunciado da atividade e copiar a saída.
  • Entregar código que você não sabe explicar linha por linha.

Vale — e ajuda muito

  • Colar a mensagem de erro e perguntar o que ela significa.
  • Pedir para explicar um trecho de código linha por linha.
  • Pedir exercícios extras sobre o assunto da aula.
  • Pedir revisão do seu código: "o que dá pra melhorar aqui?"

Critério prático: se você não consegue explicar o código que entregou, ele não é seu. Na avaliação oral isso aparece na primeira pergunta.

Prompt padrão da disciplina

Cole isto no início da conversa com a IA. Ele muda o comportamento dela de "entregar resposta" para "ensinar":

Sou aluno iniciante de JavaScript. NÃO me dê o código pronto
e não resolva o exercício por mim. Explique o conceito
envolvido, aponte onde está meu erro e me dê apenas a dica
do próximo passo. Se eu insistir pedindo a resposta,
continue me guiando com perguntas.

Checklist antes da primeira aula

  • VS Code instalado e abrindo
  • Node.js instalado (node --version respondeu com um número)
  • Extensões Live Server e Code Runner instaladas
  • Conta no GitHub criada
  • Copilot ativado no VS Code (login feito)
  • Student Developer Pack solicitado (opcional, mas recomendado)
  • Uma pasta criada para a disciplina e aberta no VS Code
