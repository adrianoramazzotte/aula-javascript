Bloco 01Introdução

Olá, estudante!

Estruturas de dados sequenciais permitem o armazenamento de conjuntos de dados em uma variável JavaScript. Há dois principais tipos de estruturas de dados sequenciais na linguagem:

Arrays

Coleções de valores ordenados sequencialmente, acessados por um índice numérico.

Objetos

Coleções de dados agrupados por chave-valor, acessados pelo nome da propriedade.

Funções

Blocos declarados uma vez e executados apenas quando chamados, com entrada e retorno.

Neste módulo, você vai aprender a declarar e manipular arrays e objetos usando JavaScript e, também, a declarar funções — blocos de códigos que são declarados inicialmente, mas executados apenas quando chamados dentro do código, e que permitem o recebimento de valores como parâmetros de entrada, além do envio de informações de volta para o fluxo principal do código. Bons estudos!

Bloco 02Conceito e manipulação de array

Arrays são conjuntos de dados sequenciais armazenados em uma única variável, e os valores dentro de um array são denominados elementos. Os valores em arrays são declarados entre colchetes, separados por vírgulas, e os elementos podem ser acessados a partir da sua posição, denominada índice (FLANAGAN, 2011).

Código 1 — declarando um array 
meu_primeiro_array = ["abacate", "biscoito", "casa"];

Nesse caso, o array recebe uma coleção com três elementos: abacate, biscoito e casa, que devem ser separados por vírgula e podem ser de diversos tipos, desde strings a valores numéricos. Podemos acessar cada elemento da seguinte forma:

Código 2 — acessando pelo índice 
var meu_primeiro_array = ["abacate", "biscoito", "casa"]

console.log(meu_primeiro_array[0])   // abacate
console.log(meu_primeiro_array[1])   // biscoito
console.log(meu_primeiro_array[2])   // casa
A contagem começa do zero

Note que o primeiro elemento, abacate, é encontrado na posição 0 do array, e não na posição 1. Em JavaScript — e em muitas outras linguagens — a contagem começa da posição 0.

Tamanho do array: a propriedade length

Para obtermos o tamanho total de elementos em um array, usamos a propriedade length:

Código 3 — length 
var meu_primeiro_array = ["abacate", "biscoito", "casa"]
console.log(meu_primeiro_array.length)   // 3
Propriedade ou método?

Propriedades são características de um objeto JavaScript, logo, não precisam ser declaradas seguidas de parênteses — diferentemente dos métodos, que requerem parênteses.

Recortando um array: slice()

Se quisermos buscar um conjunto de elementos desse array (um subarray), podemos usar o método slice(), informando como entradas: (1) a posição de início e (2) a posição final — será considerada a posição anterior a esse índice para composição do subarray.

Assinatura do método 
ARRAY.slice(início, posição posterior ao fim)
Código 4 — slice() 
var meu_primeiro_array = ["abacate", "biscoito", "casa"]

dois_primeiros_elementos = meu_primeiro_array.slice(0,2)
console.log(dois_primeiros_elementos)   // [ 'abacate', 'biscoito' ]

dois_ultimos_elementos = meu_primeiro_array.slice(1,3)
console.log(dois_ultimos_elementos)     // [ 'biscoito', 'casa' ]

Adicionando elementos: push() e unshift()

Podemos, ainda, criar arrays vazios declarando um nome de variável que receba colchetes vazios — novo_array = [] — e preenchê-lo usando a função push(), que receberá como argumento o valor correspondente ao novo elemento:

Código 5 — push() 
// declarando um array vazio
novo_array = []

// adicionando um novo item
novo_array.push("alicate")
console.log(novo_array)   // [ 'alicate' ]

// adicionando 2 novos itens
novo_array.push("bola")
novo_array.push("cavalo")

console.log(novo_array)   // [ 'alicate', 'bola', 'cavalo' ]

Removendo elementos: pop() e shift()

Por outro lado, podemos remover elementos usando o método pop(), que remove o último elemento e retorna o valor, que pode ser armazenado em uma variável:

Código 6 — pop() 
novo_array = ["alicate", "bola", "cavalo"]

valor_removido = novo_array.pop()   // remove o último elemento
console.log(valor_removido)         // cavalo
console.log(novo_array)             // [ 'alicate', 'bola' ]

Para apagar o primeiro elemento, é possível utilizar o método shift():

Código 7 — shift() 
novo_array = ["alicate", "bola"]

console.log(novo_array)   // [ 'alicate', 'bola' ]
novo_array.shift()        // apaga o primeiro elemento
console.log(novo_array)   // [ 'bola' ]

Da mesma forma, podemos adicionar elementos no começo usando unshift():

Código 8 — unshift() 
novo_array = ["bola"]

novo_array.unshift("avestruz")
console.log(novo_array)   // [ 'avestruz', 'bola' ]

Removendo do meio: indexOf() e splice()

Também podemos remover elementos específicos de um array — como um elemento que se encontra no meio, e não apenas nas extremidades. Entretanto, para especificar esse elemento, é preciso, em primeiro lugar, saber sua posição. Para isso, usamos o método indexOf() em combinação com o método splice():

Código 9 — indexOf() e splice() 
lista = ["a", "b", "c", "d", "e"]   // nova lista com 5 elementos

indice_de_c = lista.indexOf("c")    // descobre o índice de "c"
console.log(indice_de_c)            // 2

console.log(lista[indice_de_c])     // confirmando que o item está certo (retorna c)

lista.splice(indice_de_c, 1)        // removendo apenas o elemento "c"
console.log(lista)                  // [ 'a', 'b', 'd', 'e' ]
MétodoO que faz
indexOf()Retorna o índice de um determinado elemento enviado como argumento. Perceba que a letra “O” de indexOf está em maiúsculo.
splice()Remove elementos a partir de uma determinada posição passada como primeiro argumento; o segundo argumento indica quantos elementos queremos remover.

Ordenando: sort()

Por fim, para ordenar um array, é possível usar o método sort():

Código 10 — sort() alfabético 
lista_numerica = [42, 16, 8, 15, 23, 4]

lista_numerica.sort()         // ordenando alfabeticamente
console.log(lista_numerica)   // [ 15, 16, 23, 4, 42, 8 ]
Uma ordenação inesperada

Nesse caso, a ordenação foi feita incorretamente, pois o método sort() ordena alfabeticamente — com base no código ASCII. Para ordenar numericamente, é preciso informar um critério de comparação.

Código 11 — sort() numérico 
lista_numerica = [42, 16, 8, 15, 23, 4]

lista_numerica.sort((a, b) => a - b)   // ordenando numericamente
console.log(lista_numerica)            // [ 4, 8, 15, 16, 23, 42 ]

A sintaxe ficou um pouco mais complicada ao incorporarmos o símbolo =>, tratando-se de uma arrow function. Entretanto, para entender isso, é necessário, em primeiro lugar, saber o que são funções.

Bloco 03Funções

Funções (function) são blocos de códigos que não são imediatamente executados quando um script é interpretado; eles só são executados ou invocados quando ocorre uma chamada pelo nome da função seguido de parênteses (CROCKFORD, 2008; MARIANO; MELO-MINARDI, 2017).

Sim, já vimos muitas funções, como alert(), que é uma função nativa (built-in) e exibe uma caixa de diálogo na tela, assim como alguns métodos — slice(), splice(), push() e pop() — usados para manipulação de arrays. Os métodos são funções aplicadas no contexto de um objeto específico; o que muda é a forma como são chamados: digitando o nome da variável seguido de um ponto, o nome do método e parênteses.

Código 12 — sintaxe básica de uma função 
// declaração da função
function NOME-DA-FUNÇÃO(parâmetros de entrada){
       comandos
}
// chamada da função
NOME-DA-FUNÇÃO(ARGUMENTOS DE ENTRADA)

Em resumo, funções são blocos de código que contêm uma série de comandos pré-desenvolvidos usados para reduzir o tempo gasto na resolução de um problema. Imagine, por exemplo, que queremos ordenar um array: há muitas formas de fazer isso (muitos algoritmos), mas vamos resolver de um modo bem simples — analisar cada elemento da lista e compará-lo com todos os outros para ver qual é o menor e, assim, movê-lo para o começo da lista.

Selection sort

Essa estratégia de ordenação é denominada selection sort e não é o melhor algoritmo para essa tarefa, pois sempre fará comparações de todos contra todos, tendo uma complexidade O(n²). Viu como você teria de se preocupar com muitos detalhes para ordenar um simples array? Vimos anteriormente que bastaria usar o método sort() — e isso destaca como funções permitem que você não se preocupe com problemas de soluções já bem estabelecidas e foque naquilo que está realmente tentando resolver.

Criando as suas próprias funções

De fato, perceba que usamos apenas funções já definidas pelo JavaScript. Entretanto, podemos criar nossas próprias funções. Em JavaScript há muitas formas de declarar funções; por exemplo, elas podem ser declaradas com a palavra reservada function (FLANAGAN, 2011):

Código 13 — função soma 
function soma(a, b){
       return a+b        // esta linha não é executada até a função ser chamada
}

resultado = soma(2, 3)   // chamada da função (argumentos de entrada: 2 e 3)
console.log(resultado)   // 5

console.log(soma(10, 10)) // 20

Aqui, criamos uma simples função que soma dois números. Nossa função se chama soma e recebe dois parâmetros: a e b. Dentro do bloco, a função faz uma única coisa: retorna o valor da soma de a e b.

  1. A função não roda sozinhaAo executarmos esse código, o conteúdo do bloco da função não é executado imediatamente. Uma função só será executada quando for feita a chamada (apresentada na linha 5).
  2. Reaproveitamento de códigoPodemos fazer quantas chamadas de função quisermos (como ilustrado na linha 8). Por isso, dizemos que funções são estruturas que permitem o reaproveitamento de código.
  3. Parâmetros e argumentosNa chamada da função, enviamos dois argumentos, que foram aplicados aos parâmetros declarados. No exemplo, o parâmetro a recebeu o primeiro argumento (2), enquanto b recebeu o segundo (3).
  4. A palavra returnPermite que o resultado da soma seja retornado ao mesmo ponto da chamada. O uso de return é opcional: poderíamos, por exemplo, apenas imprimir o resultado diretamente na função.
  5. Os parênteses são obrigatóriosAs funções poderiam, ainda, não possuir parâmetros; entretanto, na chamada da função, deve-se sempre incluir os parênteses.

Curiosidades ⇒ arrow functions

Arrow functions (funções de seta) são uma notação JavaScript introduzida no ECMAScript versão 6 (ES6) para declarar funções. Elas foram criadas com o objetivo de tornar o JavaScript mais simples — apesar de alguns desenvolvedores discordarem disso. Por exemplo, a função:

Notação tradicional 
function soma(a, b){
       return a+b
}

…poderia ser declarada usando-se arrow functions:

Notação com arrow function 
soma = (a, b) => a+b

console.log(soma(2, 3))   // 5

Neste bloco, você aprendeu a declarar suas próprias funções em JavaScript. Agora, você está apto a estender as funcionalidades básicas da linguagem e criar suas próprias funções, que poderão ser reaproveitadas.

Bloco 04Objetos

Objetos são um tipo de dado fundamental para a linguagem JavaScript; eles armazenam coleções de chaves e valores denominados propriedades. Aqui, devemos fazer um adendo: o conceito de objetos JavaScript é equivalente ao conceito de hash, dicionário ou array associativo em outras linguagens de programação (FLANAGAN, 2011).

Criando objetos

Você pode criar um objeto utilizando o comando new Object(); entretanto, há formas mais simples utilizando chaves. Veja como a sintaxe pode ser construída:

Sintaxe mínima 
meu_primeiro_objeto = { "chave": "valor" }

Note que chaves e valores são separados por dois pontos. Além disso, é possível inserir múltiplos pares de chave e valor, desde que estejam separados por vírgula:

Código 14 — múltiplos pares 
objeto = {
       "chave1":"valor",
       "chave2":"valor",
       "chave3":"valor"
}
Chaves devem ser únicas

A chave deve ser única, ou seja, não se pode ter duas chaves com o mesmo nome em um mesmo objeto.

Consultando uma chave

Há duas formas de acessar valores individualmente em um objeto:

  1. Usando ponto (nome-objeto.propriedade): deve-se chamar o nome do objeto seguido da propriedade que se deseja acessar.
  2. Usando colchetes (nome-objeto['propriedade']): deve-se chamar o nome do objeto seguido da propriedade desejada entre colchetes e aspas.
Código 15 — duas formas de acesso 
objeto = {
     "chave1":1,
     "chave2":2,
     "chave3":3
}

// 1ª forma de acesso
valor_chave_1 = objeto.chave1
console.log("O valor da chave1 é", valor_chave_1)   // O valor da chave1 é 1

// 2ª forma de acesso
valor_chave_2 = objeto['chave2']
console.log("O valor da chave2 é", valor_chave_2)   // O valor da chave2 é 2

Observe que, no exemplo prévio, as chaves apontam para valores numéricos — mas os objetos aceitam dados de todos os tipos, como valores booleanos, strings, números, arrays e, até mesmo, outros objetos. Agora, veja um exemplo um pouco mais complexo:

Código 16 — objeto aninhado 
objeto = {
        "chave1":{ "camada1_1":5 },
        "chave2":['abacate', 'bola', 'cavalo']
}

Aqui, temos um objeto com duas chaves. A primeira recebe como valor outro objeto, que possui uma única chave camada1_1. Para acessar o valor nessa chave específica, pode-se executar o seguinte código:

Acessando a camada interna 
objeto = {
        "chave1":{ "camada1_1":5 },
        "chave2":['abacate', 'bola', 'cavalo']
}

// Acessando o valor da chave "camada1_1"
valor_1 = objeto.chave1.camada1_1
console.log(valor_1)   // 5

Na chave2, nosso objeto recebe um array com três valores. Note que não podemos usar a notação de ponto nesse caso, pois arrays são acessados usando-se o índice; assim sendo, podemos usar a notação de colchetes. No exemplo a seguir, usamos esse tipo de notação para coletar o segundo elemento do array da chave2 — note que o segundo elemento é indexado na posição 1:

Acessando um item do array interno 
objeto = {
        "chave1":{ "camada1_1":5 },
        "chave2":['abacate', 'bola', 'cavalo']
}

// Imprimindo o 2º elemento do array da chave2
valor_2 = objeto.chave2[1]
console.log(valor_2)   // bola

Percorrendo um objeto

Podemos percorrer um objeto inteiro com o auxílio de um laço de repetição. Observe o exemplo a seguir:

Código 17 — for...in 
objeto = {
       "chave1":{ "camada1_1":5 },
       "chave2":['abacate', 'bola', 'cavalo']
}
for(i in objeto){
       chave = i                     // coleta a chave
       valor = objeto[i]             // pega o valor correspondente à chave
       console.log(chave, "->", valor) // imprime chave e valor atual
}
Saída no consolechave1 -> { camada1_1: 5 } chave2 -> [ 'abacate', 'bola', 'cavalo' ]

Note que usamos a palavra reservada in para recuperar todas as chaves no objeto. Nesse caso, a cada rodada do laço for, uma nova chave será avaliada pelo bloco.
