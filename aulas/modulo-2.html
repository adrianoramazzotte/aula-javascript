Módulo 2

Estruturas condicionais

Neste módulo, você conhecerá as três principais estruturas condicionais da linguagem: if, else... if e else — os comandos que permitem ao seu programa tomar decisões.

40 minutos Blocos if else else if

Bloco 01Introdução

Olá, estudante!

Linguagens de programação interpretadas, como JavaScript, são capazes de receber conjuntos de comandos — denominados scripts — e processá-los sequencialmente, ou seja, linha a linha (pelo menos na programação procedural). Entretanto, JavaScript, assim como outras linguagens, fornece estruturas de controle que permitem que partes específicas do código, denominadas blocos, sejam executadas apenas SE determinadas condições forem verdadeiras. Caso contrário, o bloco de códigos delimitado pela estrutura condicional será ignorado, alterando, assim, o fluxo do código.

if

Executa um bloco de código se uma condição expressa entre parênteses for verdadeira.

else if

Funciona de maneira similar, mas deve ser usado apenas se uma condição if for apresentada inicialmente.

else

Executa um bloco se nenhuma condição anterior for verdadeira, garantindo que pelo menos um bloco seja executado.

Nos próximos blocos, vamos explorar como esses comandos JavaScript funcionam na prática. Bons estudos!

Bloco 02Estrutura condicional if

Em programação, estruturas condicionais alteram o fluxo do código, verificando se expressões avaliadas são atendidas ou não. Para essa comparação, pode-se utilizar a palavra reservada if (na tradução para o português, “se”). E antes de apresentarmos um exemplo, vamos, primeiro, introduzir o conceito de bloco.

Um bloco é um pedaço de código delimitado por chaves { }.

Código 1 — anatomia de um bloco 
BLOCO {
       COMANDOS JAVASCRIPT;
}
Indentação

Note que utilizamos um espaçamento antes dos comandos inseridos dentro de um bloco: a isso damos o nome de indentação. Em JavaScript ela não é obrigatória, entretanto, seu uso constitui uma boa prática de programação, uma vez que permite ao desenvolvedor identificar mais facilmente se um conjunto de códigos pertence ou não a um bloco.

Em um bloco condicional if, todos os códigos presentes no bloco só serão executados SE a condição for verdadeira. Veja:

Código 2 — condicional if 
if(true){
console.log("Olá mundo!");
}
if(false){
console.log("Esta mensagem não será executada");
}

Se executarmos este código, veremos apenas a mensagem Olá mundo! Isso ocorrerá porque os comandos em um bloco só são executados se a condição é verdadeira.

Vamos utilizar nosso exemplo apresentado nos módulos anteriores para verificar se um número é par ou ímpar:

Código 3 — testando se x é par 
x = 1;

// se x for um número par
if(x % 2 == 0){
       console.log("A variável x é um número par");
}

Observe que, ao executarmos o código acima, nada aparece no console, pois x não é um número par. Isso ocorre porque os comandos dentro do bloco só são executados se a condição de entrada é verdadeira. Veja o que acontece se invertermos a pergunta:

Código 4 — testando se x é ímpar 
x = 1;

// se x for um número ímpar
if(x % 2 == 1){
       console.log("A variável x é um número ímpar");
}
Saída no consoleA variável x é um número ímpar

Avaliando expressões mais complexas

Podemos, ainda, avaliar expressões mais complexas organizando-as com parênteses, além de operadores lógicos e relacionais. No exemplo a seguir, usamos duas expressões para avaliar a relação de uma variável x igual a 5 e uma variável y igual a 3:

Código 5 — relação entre variáveis 
x = 5
y = 3

if((x < y)||(x % 2 == 1)){
      console.log("x é maior do que y OU x é um número ímpar")
}

Veja que, neste código, avaliamos uma condição um pouco mais complexa — ((x < y)||(x % 2 == 1)). Vamos analisá-la por partes:

Operador/expressãoSignificado
(Parêntese de abertura da expressão que abriga as expressões 1 e 2. São necessários pois utilizaremos duas expressões.
(x < y)Primeira expressão. Verifica se a variável x é menor do que y. Neste caso, é falso.
||Operador OR. Retornará verdadeiro se alguma das expressões for verdadeira.
(x % 2 == 1)Segunda expressão. Verifica se x é ímpar, ou seja, se o módulo de x por 2 tem resto igual a 1. Neste caso, é verdadeiro.
)Parêntese de fechamento da expressão principal. Como uma delas retornou verdadeiro, o resultado final será verdadeiro e o bloco será executado.

Quadro 1 — Significado de cada parte da expressão condicional ((x < y)||(x % 2 == 1)). Fonte: elaborado pelo autor.

Observe, por fim, que os códigos existentes entre as chaves { } serão executados uma vez que a expressão final é verdadeira. Logo, será impressa a mensagem:

Saída no consolex é maior do que y OU x é um número ímpar

Note que você pode adicionar quantas expressões quiser, mas à medida que adicionar mais expressões, o código se tornará mais complexo, o que poderá dificultar sua manutenção. Repare também que executar este código:

Código 6 — uma condição composta 
if((x < y)||(x % 2 == 1)){
      console.log("x é maior do que y OU x é um número ímpar")
}

…é a mesma coisa que executar este:

Código 7 — dois ifs encadeados 
if(x < y){
      console.log("x é maior do que y OU x é um número ímpar")
}
if(x % 2 == 1){
      console.log("x é maior do que y OU x é um número ímpar")
}
Boa prática

Encadear muitos comandos if em sequência não é uma boa prática, uma vez que cada um será testado individualmente. Ao executar testes condicionais relacionados entre si, é possível usar outra estrutura condicional — que veremos a seguir.

Bloco 03Estrutura condicional if...else

Você viu que a estrutura if verifica se uma determinada expressão é verdadeira ou não e que, em caso negativo, nenhum comando no bloco é executado. Entretanto, o JavaScript fornece a instrução else para declarar um bloco extra a ser executado caso o bloco if falhe (CROCKFORD, 2008). Observe a sintaxe:

Código 8 — sintaxe do if...else 
if(CONDIÇÃO){
       COMANDOS ...
}
else{
       COMANDOS...
}

Agora, observe como podemos utilizar if e else juntos:

Código 9 — if e else 
x = 1;

if(x % 2 == 0){
       console.log(x, "é par")
}
else{
       console.log(x, "é ímpar")
}

Aqui, verificamos se o resto da divisão de x por 2 seria igual a 0, ou seja, se se tratava de um número par. Uma vez que a condição se mostrou falsa, o bloco else foi executado. Nesse caso, o console imprimiu a mensagem “1 é ímpar”. Experimente alterar o valor de x para analisar o comportamento do código.

Operador vírgula

Note que, ao usarmos o comando console.log(), os valores são separados por vírgulas. O operador vírgula permite que variáveis sejam intercaladas com strings; dessa forma, as mensagens exibidas para o usuário tornam-se mais dinâmicas. Por exemplo:

Intercalando variável e texto 
x = 1;
console.log(x, "é par")

x = 100;
console.log(x, "é par")
Cuidado com a mensagem

O primeiro comando exibirá “1 é par” — o que não é verdade! Por isso, tome cuidado ao transcrever seus logs de aviso. Ao alterar o valor de x para 100, a mensagem passa a ser “100 é par”.

Entretanto, ao usar essa funcionalidade, tome cuidado ao verificar se a variável foi declarada anteriormente. Por exemplo:

Variável não declarada 
console.log(y)
Erro produzido

ReferenceError: y is not defined — Erro de referência: y não está definido.

Encadeando instruções if e else

Note que podemos encadear várias instruções if e else para construir blocos de códigos mais complexos (MARIANO; MELO-MINARDI, 2017). Por exemplo:

Código 10 — if e else aninhados 
x = 1;

if(x % 2 == 0){
      if(x > 0){
             console.log(x, "é um número par e positivo")
      }
      else{
             console.log(x, "é um número par e negativo")
      }
}
else{
      if(x > 0){
             console.log(x, "é um número ímpar e positivo")
      }
      else{
             console.log(x, "é um número ímpar e negativo")
      }
}
Saída no console1 é um número ímpar e positivo

E podemos construir códigos mais robustos usando a instrução else...if, que veremos no próximo bloco.

Bloco 04Estrutura condicional if...else if...else

Você aprendeu a utilizar a instrução if para verificar uma determinada condição e que é possível utilizar a condição else caso o if seja falso. Entretanto, a instrução else só pode ser ligada a uma instrução if, ou seja, não é possível encadear mais do que duas condições usando apenas essas duas instruções. Por isso, o JavaScript fornece a instrução else if.

A instrução else if pode ser intercalada em blocos if... else para permitir que mais condições sejam avaliadas (FLANAGAN, 2011):

Código 11 — sintaxe do encadeamento 
if (condicao){
      ...
}
else if(condicao 2){
      ...
}
else if(condicao 3){
      ...
}
else if(condicao n){
      ...
}
else{
      ...
}
Regras de uso
  • É possível intercalar quantas condições o desenvolvedor achar necessário.
  • Para usar else if, é necessário que haja pelo menos uma instrução if declarada imediatamente antes.
  • O comando else não é obrigatório após o uso da instrução else if.

Exemplo prático: classificação escolar

Imagine que você está desenvolvendo um programa para avaliar a idade de alunos cadastrados no ensino e que ele deve avaliar a idade apresentada por um usuário, bem como determinar o grau de ensino que o estudante, teoricamente, deveria estar cursando. Na teoria, os alunos devem ter as seguintes idades para atender a cada nível educacional:

NívelFaixa etáriaExpressão em JavaScript
Pré-escolade 4 a menos que 6 anosidade >= 4 && idade < 6
Ensino Fundamentalde 6 a menos que 15 anosidade >= 6 && idade < 15
Ensino Médiode 15 a menos que 18 anosidade >= 15 && idade < 18
Fora do padrãoqualquer outra idadeelse

Alunos fora dessa faixa etária devem ser classificados como fora do padrão escolar.

Agora, vamos implementar isso usando JavaScript:

Código 12 — classificação por idade 
idade = 13

if(idade >= 4 && idade < 6){
      console.log("Pré-escola");
}
else if(idade >= 6 && idade < 15){
      console.log("Ensino fundamental");
}
else if(idade >= 15 && idade < 18){
      console.log("Ensino médio");
}
else{
     console.log("Aluno está fora do padrão escolar.")
}
console.log("FIM")
  1. Linha 1 — declaraçãoDeclaramos a variável idade, que será avaliada nas linhas 3, 6, 9 e 12.
  2. Linha 3 — primeiro testeVerifica se idade é maior ou igual a 4 e, ao mesmo tempo, menor que 6. Essa condição é falsa, logo, o bloco é ignorado (a linha 4 não é executada).
  3. Linha 6 — segundo testeVerifica se a variável é maior ou igual a 6 e, ao mesmo tempo, menor que 15. Essa condição é verdadeira, logo, o bloco é executado (linha 7).
  4. Linhas 9 e 12 — ignoradasComo uma condição já foi atendida, os outros blocos else if ou else em sequência são ignorados.
  5. Linha 15 — continuaçãoA execução do código continua apenas na linha 15.
Saída no consoleEnsino fundamental FIM
Desafio

Teste o código acima alterando o valor da variável idade. Veja o que acontece se você colocar um valor não numérico.

Bloco 05Estudo de caso

Desafio profissional

Um banco de currículos para os quase aprovados

Após você detectar e resolver o problema no sistema de aprovações para a segunda etapa do processo seletivo de estágio da empresa em que foi recém-contratado, o setor de recursos humanos decidiu alterar as regras de aprovação para a próxima etapa.

As regras iniciais aprovavam apenas estudantes com nota mínima de 70% na prova e com pelo menos três semestres de um curso superior; logo, os candidatos que não conseguiam cumprir ambos os objetivos eram reprovados. Entretanto, a equipe de RH chegou à conclusão de que estava perdendo potenciais talentos que ainda não tinham cursado a quantidade mínima de semestres, mas que tinham obtido nota maior ou igual a 70% da prova.

Por isso, foi requisitada uma alteração no código: caso o aluno atendesse tais condições, o sistema deveria emitir a mensagem “Você foi incluído em nosso banco de currículos”.

Realize alterações no código fonte da função primeiraEtapa() para incluir essa nova regra. Para testar, transcreva o código a seguir em seu próprio editor, realizando as modificações necessárias para o seu correto funcionamento, de acordo com o que foi especificado.

Código 14 — ponto de partida 
// determina aprovados para a segunda etapa
function primeiraEtapa(acertos_na_prova,
                       semestres_cursados){
    /*
    * Help:
    * acertos_na_prova recebe a quantidade de acertos na prova
    * semestres_cursados: semestres cursados
    */
    // regras para aprovação
    const total_de_questoes = 20
    const nota_minima_aprovacao = 0.7
    const minimo_semestres = 3

    // calcula a nota %
    let nota = acertos_na_prova / total_de_questoes

    // calcula se vai ser aprovado ou não
    if((nota >= nota_minima_aprovacao) &&
              (semestres_cursados >= minimo_semestres)){
         return "Aprovado";
    }
    else{
         return "Reprovado";
    }
}

Função completa — teste dos três casos 
function primeiraEtapa(acertos_na_prova, semestres_cursados){
    const total_de_questoes = 20
    const nota_minima_aprovacao = 0.7
    const minimo_semestres = 3

    let nota = acertos_na_prova / total_de_questoes

    if((nota >= nota_minima_aprovacao) &&
       (semestres_cursados >= minimo_semestres)){
        return "Aprovado";
    }
    else if(nota >= nota_minima_aprovacao){
        return "Você foi incluído em nosso banco de currículos";
    }
    else{
        return "Reprovado";
    }
}

console.log(primeiraEtapa(10, 5));  // nota 50%, 5 semestres
